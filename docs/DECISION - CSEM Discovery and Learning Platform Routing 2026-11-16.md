# CSEM Public Discovery and Learning Platform Routing
Date: 2026-11-16
Status: decision recorded on website feature branch; no public navigation or deployment change.

## Current evidence
`app/learning/page.tsx` exists and describes MAXYRON learning domains and Applied AI Engineering. The inspected source does not yet include a dedicated CSEM entry. The separate `Odogwo/maxyron-learning` development branch contains a nine-workspace learner application preview. `Odogwo/maxyron-csem` contains the Computing discipline, assessment specifications and governance; it is private.

## Website responsibility
The corporate website should present a truthful CSEM programme overview, current availability, audience, learning outcomes, and an explicit route to the shared MAXYRON Learning application **only after a tested and approved public destination exists**. Do not link public visitors to a private GitHub repository. No enrollment, certification, operational assessment, public application URL or accreditation should be claimed without evidence.

## Proposed information architecture
Corporate `/learning` → CSEM programme discovery page (route to be selected after existing route audit) → approved MAXYRON Learning application → CSEM discipline content release. The public site remains separate from authenticated learner records and assessments.

## Acceptance
Verify website route, accessibility, copy, privacy, destination, build, preview and release approval before production deployment. This file documents direction only and does not authorize a merge or deployment.
